# 默认助手提示词冲突修复与验证

## 修改

这些规则来自固定运行时提示词、工具目录与动作结果，持久记忆只作为背景追加。修改保持原有系统消息顺序：普通助手的有效提示词在最前面，后接运行约束、可选终端和网页规则、记忆及 Skills；角色会话仍使用角色卡。

| 原有冲突 | 修复后的行为 |
| --- | --- |
| 全局禁止在无障碍错误后使用坐标，与虚拟屏 Root 后端冲突 | 区分主屏与虚拟屏。虚拟屏仅在新观察、Root 授权有效、工具公开且没有保护性暂停时，使用本 display 的坐标或焦点文本；保护拒绝、权限撤销和结果未知仍遵守恢复边界 |
| “默认不抓图、空树再抓图”与虚拟屏空树自动附图冲突 | 系统提示与工具 Schema 共用观察合同。主屏默认无图；虚拟屏省略 `include_screenshot` 时空树自动附图，显式 `false` 禁止附图；已有的新图足够时直接使用 |
| 输入工具鼓励长文本剪贴板，系统提示又禁止剪贴板 | 中文、emoji、长文本直接调用 `type_text`。内部 Root 粘贴不要求模型先调用剪贴板工具；明确复制任务或工具要求的粘贴才准备剪贴板 |
| `screen_changed=false` 被解释为动作失败，应立即换方式 | 该值仅描述采样节点与应用窗口。没有基线或有效节点时为 `null`，不同节点上限按共同采样范围比较；变化不能证明业务完成，未变化不能证明失败或卡死 |
| 默认语言、详略、Markdown 规则覆盖用户编辑的助手提示词 | 交流偏好依次使用当前用户明确要求、有效助手提示词、内置默认。记忆不覆盖这些要求；工具合同、权限、路由、保护暂停与真实结果核验始终适用 |

加载场景引导模型有界等待。确认没有命中、且不会重复提交的普通点击，使用新观察最多补试一次，并继续受原有停滞预算约束；发送、发布、支付等效果未知时只读核对。节点工具不可用时不调用 `wait_for_text`，不通过循环观察、等待或微调坐标绕过保护。这些是共享提示与结果说明，没有新增自动重放动作。

提示词设置说明同步更新英文、简体中文与繁体中文，明确编辑内容位于系统上下文前部，后续工具与权限规则仍然生效。架构说明见 [AGENT_RUNTIME.md](AGENT_RUNTIME.md)。

## 构建与单元测试

环境为 JDK 25.0.3、Android SDK 37.0。以下命令成功：

```sh
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug
```

- JVM：295 个测试类、1794 项测试，0 失败、0 错误、2 跳过。
- Lint：0 错误、402 个警告、1 个提示。
- 回归覆盖主屏/虚拟屏、记忆开关、普通/角色会话的组合，工具目录投影不修改主屏 Schema，截图省略与显式开关，以及无基线、空节点、不同采样上限、应用/窗口切换与控件状态变化。

## 真机验证

手机为 vivo V2419A，Android 16 / OriginOS 6，KernelSU 与 LSPosed，使用 USB ADB 安装 Debug 和独立测试 APK。测试使用不含账户、网络或用户数据的构造页面，运行结束恢复原设置。

| 测试模式 | 检查数 | 覆盖 |
| --- | ---: | --- |
| `gui_no_tree` | 15 | 空树默认自动附图、显式禁止截图、动作后只附一张新图、变化未知、坐标操作保持虚拟屏、点击只发生一次 |
| `gui_edge` | 20 | checked 状态变化、确认未命中的点击、中文和 emoji 替换及追加 |
| `gui_slow_submit` | 13 | 点击已经受理但 5 秒内节点不变，有界等待后确认结果，提交只发生一次 |

共 48 项检查通过。测试入口：

```sh
adb -s <usb-device> shell am instrument -w -r -e mode gui_slow_submit \
  io.github.mangi.eta.test/io.github.mangi.eta.validation.DeviceValidationRunner
```

OriginOS 在连续重启测试进程时偶尔未重新绑定已启用的无障碍服务，这些失败发生在 GUI 操作之前，恢复绑定后重跑通过。慢加载测试最初因 Button 节点呈全大写而未匹配混合大小写的等待条件；测试现使用大小写无关的精确正则。未保留试验中的额外节点缓存刷新改动。

验证证明提示词组装、工具合同与受控页面行为符合预期；未调用线上模型，不能据此保证任意模型都会遵循提示词。需要下一次真实会话观察模型的实际选择。
