# Eta 3.3.1-beta.2

基于上游 3.3.0，版本码 `2026101101`。以下为相对 `3.3.1-beta.1` 的更新。

## 更新内容

- 虚拟屏预览统一使用系统原生画中画，移除旧的自绘悬浮窗、折叠气泡、标题和关闭按钮。支持系统拖动、贴边收起、放大进入控制页和关闭；收起、隐藏或锁屏时停止预览抓帧，可见时最多 10fps。沿用旧预览开关，已开启的用户升级后直接使用画中画。
- `swipe` 支持单指连续经过多个坐标点，整段手势不抬手，可画折线、曲线和闭合路径。主屏、Root 后备和虚拟屏使用同一套路径合同，动作指示器显示实际轨迹。
- 修复虚拟屏控制页的复杂手势被压成起终点直线的问题。现在保留移动事件与历史采样，横屏转换每个路径点；密集路径压缩时优先保留转角、回折和闭合形状，中途取消或关闭触控不会重放旧手势。
- 统一主屏与虚拟屏的观察、截图和文本输入提示。虚拟屏空 UI 树时可自动附图，显式禁止截图仍然生效；中文、emoji 和长文本可直接使用文本工具。
- 改善动作结果核验：界面未变化不直接判断为失败或卡死，缺少有效观察时不声称结果已确认。加载和未命中场景采用有界等待或补试，避免重复提交；保护性暂停仍然阻止后续动作。
- 明确默认助手提示词与记忆的优先级。当前用户要求优先，其次是有效助手提示词，再使用内置交流默认；记忆只提供背景，工具与权限规则继续生效。设置说明同步更新英文、简体中文和繁体中文。
- 首页侧边栏的权限入口移入「更多」折叠项。

## 使用说明

虚拟屏沿用 Root 条件；预览需要允许 Eta 使用系统画中画，可在虚拟屏设置中关闭。画中画预览用于查看，放大后进入可触控的控制页。

连续手势目前支持单指；控制页在抬手后按整段轨迹执行。`swipe.path` 最多包含 64 个坐标点，与原起终点参数互斥。

安装包沿用 Eta-vivo 的发布证书，可覆盖升级本仓库上一 Beta；Debug 包和其他证书签名的安装包使用各自签名。
