# Eta 3.3.1-beta.3

基于上游 3.3.0，版本码 `2026101102`。以下为相对 `3.3.1-beta.2` 的更新。

## 更新内容

- 重构虚拟屏查看器：应用画面占满可用区域，移除 Eta 顶栏、边框和固定导航按钮。保留手机状态栏，并避开状态栏和挖孔高度；横屏画面继续顺时针旋转适配。
- 复用 3.3.0 操作胶囊，支持拖动、左右吸边和自动隐藏。默认只显示边缘把手；展开后提供暂停、继续、停止、补充指令、键盘、操作记录和退出查看。去掉返回、主页、菜单、触控切换和关闭虚拟屏的叉，修正状态文字与指示符对齐。任务氛围光显示在虚拟屏查看器内。
- 全屏显示改用系统图层镜像，实时画面避开 JPEG 编解码与轮询，目标刷新率为 120fps。AI 观察仍按需截图；系统 PiP 和兼容预览保持最高 10fps，隐藏或收起后停止持续编码。
- 手动触控改为连续透传 DOWN、MOVE、UP 和 CANCEL，按住和移动时即时响应，保留轨迹、历史采样、指针 ID 和时序。支持多指及超过两秒的按住；退出、旋转或断连会取消未结束的手势。
- 修复打开查看器或展开 PiP 就暂停任务的问题。仅在画面就绪后触摸应用区域才接管；AI 长手势执行中也能手动接管，继续后必须重新观察，旧动作不会重放。
- 移除 Eta 查看器和 PiP 的截图限制，支持系统截图与后台任务缩略图。
- 修复结束 Eta 进程后续聊卡在 `NO_OBSERVATION` 的问题。会话自动重建虚拟屏并尝试打开上次应用，返回明确的新观察指引；只保存应用入口，不重放旧深链、点击或提交。
- Eta 与虚拟屏使用独立的后台任务卡片，重复打开复用同一查看器。增加 OriginOS 多任务声明，解决桌面只显示其中一张卡片的问题。

## 使用说明

虚拟屏沿用 Root 条件，系统画中画需要允许 Eta 使用 PiP。全屏实时镜像已在 vivo V2419A / Android 16 / OriginOS 6 / KernelSU + LSPosed 验证；其他 ROM 或镜像不可用时使用兼容预览，抬手后执行手势。

120fps 取决于手机刷新率、系统调度和目标应用实际绘制能力。本机约 30 秒动画测量的平均呈现间隔为 8.3147ms，P95/P99 为 9.8116/10.6481ms；这不代表所有应用都能达到 120fps，也不代替长期温控测试。

原生输入法跨 display 自动呼出仍受系统焦点限制，保留胶囊内的键盘入口。第三方应用自身的安全图层仍由 Android 管理。

进程结束后应用原有页面状态可能丢失，续聊会先取得新观察并核对进度。应用占用冲突继续遵守已有重启授权；显式关闭虚拟屏会忘记本会话的恢复入口。

OriginOS 已有安装升级后可能缓存旧的多任务规则，若后台仍只显示一张卡片，重启桌面或手机后生效。

安装包沿用 Eta-vivo 的发布证书，可覆盖升级本仓库上一 Beta；Debug 包使用独立签名。
